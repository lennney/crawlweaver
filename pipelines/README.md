# Pipelines

Content production pipelines integrated into crawlweaver.

| Pipeline | Origin | Description |
|---|---|---|
| `youtube-content/` | `lennney/youtube-content-factory` (archived) | AI Agent YouTube content production platform |
| `youtube-to-article/` | `lennney/youtube-to-article` (archived) | YouTube → DIY article pipeline with AI rewrite + SEO |

## Usage

Each pipeline is self-contained with its own `pyproject.toml`, tests, and docs. Run them independently or integrate with crawlweaver's core extraction tools.
