# YouTube Cookies Template
#
# This file is NOT used directly. You need to export your own cookies.
#
# How to get cookies:
#   1. Install yt-dlp: pip install yt-dlp
#   2. Run ONE of these commands on YOUR machine (where you're logged into YouTube):
#
#      Chrome:
#        yt-dlp --cookies-from-browser chrome --cookies cookies.txt "https://www.youtube.com" --skip-download
#
#      Firefox:
#        yt-dlp --cookies-from-browser firefox --cookies cookies.txt "https://www.youtube.com" --skip-download
#
#      Edge:
#        yt-dlp --cookies-from-browser edge --cookies cookies.txt "https://www.youtube.com" --skip-download
#
#   3. Rename cookies.txt to yt_cookies.txt and place it in this directory
#   4. Run: python cli.py setup --check
#
# The file format is Netscape HTTP Cookie File (generated by yt-dlp).
# It contains your YouTube session cookies — DO NOT share or commit this file.
